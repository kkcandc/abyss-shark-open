# ABYSS

An open-ocean shark game. Swim a living sea, hunt, grow, and chart four regions: the sunlit reef, the kelp cathedral, wreck alley, and the abyssal trench.

No accounts. No API keys. Progress stays in this browser.

## Dive

```bash
npm install
npm run dev
```

Open the local URL, then press **Dive**.

## Controls

- Mouse, or A / D, turns. Arrow up / down or R / F pitches.
- W swims faster. S eases off. The shark never fully stops.
- Shift is a stamina burst. Space or E lunges.
- Swim through small fish. Larger prey has to be lunged, and only once you are big enough.
- M opens the chart. C opens the journal. Esc pauses.
- Hunger empties while you cruise and drops faster when you sprint. Eat, or the sea takes your size back. Stamina returns when you glide, slower if you are starving.
- Surface from the pause menu to keep the shark. Begin again forgets it.

## World

The reef is home. Kelp is west, the wrecks are east, and the trench is south, past open water where tuna and a whale cross. Names on the chart appear when you arrive. Wrecks, the whale, the manta, and the things that glow are written into the journal the moment you find them.
